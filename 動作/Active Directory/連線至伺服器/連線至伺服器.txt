# ==================== 說明 ====================
# 動作：連線至伺服器  (ActiveDirectory.ConnectToServer)
# 英文名稱：Connect to server
# 用途：連線至 Active Directory 伺服器
# 位置：Active Directory
# 輸入參數：
#   LdapPath [文字] LDAP 路徑 — Active Directory 伺服器的 LDAP 路徑
#   UseAuthentication [布林，預設 False] 使用者驗證 — 指定是否需要驗證才能連線至伺服器
#   Username [文字] 使用者名稱 — 使用者的使用者名稱
#   Password [文字(可加密)] 密碼 — 使用者的密碼
#   AuthenticationType [選項，預設 Secure] 驗證類型 — 指定要使用的驗證類型
#       可用值：ActiveDirectory.AuthenticationTypes.None（無）、ActiveDirectory.AuthenticationTypes.Secure（安全）、ActiveDirectory.AuthenticationTypes.Encryption（加密）、ActiveDirectory.AuthenticationTypes.SecureSocketsLayer（安全通訊端層）、ActiveDirectory.AuthenticationTypes.ReadonlyServer（唯讀伺服器）、ActiveDirectory.AuthenticationTypes.Anonymous（匿名）、ActiveDirectory.AuthenticationTypes.FastBind（快速繫結）、ActiveDirectory.AuthenticationTypes.Signing（簽署）、ActiveDirectory.AuthenticationTypes.Sealing（密封）、ActiveDirectory.AuthenticationTypes.Delegation（委派）、ActiveDirectory.AuthenticationTypes.ServerBind（伺服器繫結）
# 產生的變數：
#   ParentDirectoryEntry [ActiveDirectoryEntry] 上層目錄項目 — 要與稍後 Active Directory 動作搭配使用的 Active Directory 項目上層
# 可能的錯誤：AuthenticationError、UnauthorizedAccessError、ServerNotOperationalError、InvalidOperationError、ActiveDirectoryError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。

# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
