# 動作：描述影像  (MicrosoftCognitive.DescribeImageMicrosoft)

# 輸入參數：
#   ServerLocation [選項，預設 WestUS] 伺服器位置 — 要用來進行此 API 呼叫的伺服器位置
#       可用值：MicrosoftCognitive.MicrosoftServerLocation.WestUS（美國西部）、MicrosoftCognitive.MicrosoftServerLocation.WestUS2（美國西部 2）、MicrosoftCognitive.MicrosoftServerLocation.EastUS（美國東部）、MicrosoftCognitive.MicrosoftServerLocation.EastUS2（美國東部 2）、MicrosoftCognitive.MicrosoftServerLocation.WestCentralUS（美國中西部）、MicrosoftCognitive.MicrosoftServerLocation.SouthCentralUS（美國中南部）、MicrosoftCognitive.MicrosoftServerLocation.WestEurope（西歐）、MicrosoftCognitive.MicrosoftServerLocation.NorthEurope（北歐）、MicrosoftCognitive.MicrosoftServerLocation.SoutheastAsia（東南亞）、MicrosoftCognitive.MicrosoftServerLocation.EastAsia（東亞）、MicrosoftCognitive.MicrosoftServerLocation.AustraliaEast（澳大利亞東部）、MicrosoftCognitive.MicrosoftServerLocation.BrazilSouth（巴西南部）、MicrosoftCognitive.MicrosoftServerLocation.CanadaCentral（加拿大中部）、MicrosoftCognitive.MicrosoftServerLocation.CentralIndia（印度中部）、MicrosoftCognitive.MicrosoftServerLocation.UKSouth（英國南部）、MicrosoftCognitive.MicrosoftServerLocation.JapanEast（日本東部）

#   ImageUrl [文字] 影像 URL — 影像的 URL 位址
#   ImageFile [FileObject] 影像檔 — 要傳輸之影像檔的完整路徑 (資料夾和檔案名稱)
#   MaxCandidates [文字，選填] 最大候選項目數 — 要傳回的侯選描述數目上限。預設值是 1
