#   ApiKey [文字] API 金鑰 — 要用來進行此呼叫的 API 金鑰
#   VersionDate [文字] 版本日期 — 要使用之 API 的發行日期
#   Location [選項，預設 UsEast] 服務端點位置 — 帳戶的服務位置。可透過資源區段中的 IBM「管理」查看
#       可用值：IBMCognitive.LanguageTranslatorServiceLocation.UsSouth（美國南部）、IBMCognitive.LanguageTranslatorServiceLocation.UsEast（美國東部）、IBMCognitive.LanguageTranslatorServiceLocation.Europe（歐洲）、IBMCognitive.LanguageTranslatorServiceLocation.Australia（澳洲）、IBMCognitive.LanguageTranslatorServiceLocation.Japan（日本）、IBMCognitive.LanguageTranslatorServiceLocation.Uk（英國）、IBMCognitive.LanguageTranslatorServiceLocation.Korea（南韓）
