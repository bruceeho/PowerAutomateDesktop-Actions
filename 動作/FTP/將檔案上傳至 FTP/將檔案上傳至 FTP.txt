# ==================== 說明 ====================
# 動作：將檔案上傳至 FTP  (FTP.UploadFiles)
# 英文名稱：Upload File(s) to FTP
# 用途：將一或多個檔案上傳至 FTP 伺服器
# 位置：FTP
# 輸入參數：
#   Connection [FtpConnectionBase] FTP 連線 — 要使用的 FTP 連線。這個變數先前必須已使用「開啟 FTP」連線動作完成指定
#   Files [List<FileObject>] 要上傳的檔案 — 要上傳的檔案
#   RemoteLocation [文字，選填] 遠端位置 — 檔案應上傳至其中的位置
#   TransferType [選項，預設 Auto] 傳輸類型 — 輸入 ASCII 或二進位來指定下載單一檔案的方法。如果無法確定檔案將採用類型，或將下載多個檔案，請選擇「自動」並按照「選項」中所指定的傳輸規則
#       可用值：FTP.FtpTransferType.Auto（自動）、FTP.FtpTransferType.Binary（二進位）、FTP.FtpTransferType.Ascii（ASCII）
#   IfFileExists [選項，預設 Overwrite] 如果檔案已存在 — 指定當檔案已經存在時應採取的行動。覆寫原始檔案或使用唯一名稱進行下載，並在結尾處新增底線和序列編號。
#       可用值：FTP.IfFtpFileExists.Overwrite（覆寫）、FTP.IfFtpFileExists.Skip（不要下載）、FTP.IfFtpFileExists.TransferWithUniqueName（使用唯一名稱下載）
# 可能的錯誤：NotConnectedError、FileNotFoundError、FTPConnectionAbortedError、UploadFileError

# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
