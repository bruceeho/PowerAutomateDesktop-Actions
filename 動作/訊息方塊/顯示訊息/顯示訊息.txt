# 動作：顯示訊息  (Display.ShowMessageDialog)

# 輸入參數：
#   Title [文字，選填] 訊息方塊標題 — 要做為訊息方塊標題使用的文字
#   Message [文字，選填] 要顯示的訊息 — 指定要顯示為訊息的文字
#   Icon [選項，預設 None] 訊息方塊圖示 — 隨訊息方塊顯示的圖示
#       可用值：Display.Icon.None（無）、Display.Icon.Information（資訊）、Display.Icon.Question（問題）、Display.Icon.Warning（警告）、Display.Icon.ErrorIcon（錯誤）

#       可用值：Display.Buttons.OK（確定）、Display.Buttons.OKCancel（確定 - 取消）、Display.Buttons.YesNo（是 - 否）、Display.Buttons.YesNoCancel（是 - 否 - 取消）、Display.Buttons.AbortRetryIgnore（中止 - 重試 - 忽略）、Display.Buttons.RetryCancel（重試 - 取消）

#       可用值：Display.DefaultButton.Button1（第一個按鈕）、Display.DefaultButton.Button2（第二個按鈕）、Display.DefaultButton.Button3（第三個按鈕）
#   IsTopMost [布林，預設 False] 訊息方塊一律保持在最上方 — 指定訊息方塊是否應一律保持在所有其他視窗之上

#   Timeout [整數，預設 3] 逾時 — 指定在自動繼續之前，要等待輸入而暫停流程的秒數
# 產生的變數：
#   ButtonPressed [文字] 按下的按鈕 — 所按下按鈕的文字
