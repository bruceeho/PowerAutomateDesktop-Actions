# 動作：顯示選取資料夾對話方塊  (Display.SelectFolder)
# 英文名稱：Display select folder dialog
# 用途：顯示選取資料夾對話方塊並提示使用者選取資料夾
# 位置：訊息方塊
# 輸入參數：
#   Description [文字，選填] 對話方塊描述 — 選取資料夾對話方塊的描述。例如「請選取您要將檔案複製到其中的資料夾」

#   SelectedFolder [FolderObject] 選取的資料夾 — 選取的資料夾
