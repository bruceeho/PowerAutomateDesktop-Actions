# ==================== 說明 ====================
# 動作：使用 OCR 擷取文字  (OCR.ExtractTextWithOCR)
# 英文名稱：Extract text with OCR
# 用途：使用指定的 OCR 引擎從指定來源擷取文字
# 位置：OCR
# 輸入參數：
#   OCREngineType [選項，預設 WindowsOcr]
#       可用值：OCR.OCREngineType.WindowsOcr、OCR.OCREngineType.Tesseract、OCR.OCREngineType.Predefined
#   OCREngine [OCREngineObject]
#   OcrSource [選項，預設 Screen] OCR 來源 — 要對其執行 OCR 作業的影像來源
#       可用值：OCR.OCRSource.Screen（畫面）、OCR.OCRSource.ForegroundWindow（前景視窗）、OCR.OCRSource.File（磁碟上的影像）
#   UseOtherLanguage [布林，預設 False]
#   WindowsOcrLanguage [選項，預設 English]
#       可用值：OCR.WindowsOcrLanguage.ChineseSimplified、OCR.WindowsOcrLanguage.ChineseTraditional、OCR.WindowsOcrLanguage.Czech、OCR.WindowsOcrLanguage.Danish、OCR.WindowsOcrLanguage.Dutch、OCR.WindowsOcrLanguage.English、OCR.WindowsOcrLanguage.Finnish、OCR.WindowsOcrLanguage.French、OCR.WindowsOcrLanguage.German、OCR.WindowsOcrLanguage.Greek、OCR.WindowsOcrLanguage.Hungarian、OCR.WindowsOcrLanguage.Italian、OCR.WindowsOcrLanguage.Japanese、OCR.WindowsOcrLanguage.Korean、OCR.WindowsOcrLanguage.Norwegian、OCR.WindowsOcrLanguage.Polish、OCR.WindowsOcrLanguage.Portuguese、OCR.WindowsOcrLanguage.Romanian、OCR.WindowsOcrLanguage.Russian、OCR.WindowsOcrLanguage.SerbianCyrillic、OCR.WindowsOcrLanguage.SerbianLatin、OCR.WindowsOcrLanguage.Slovak、OCR.WindowsOcrLanguage.Spanish、OCR.WindowsOcrLanguage.Swedish、OCR.WindowsOcrLanguage.Turkish
#   Language [選項，預設 English]
#       可用值：OCR.TesseractLanguage.English、OCR.TesseractLanguage.German、OCR.TesseractLanguage.Spanish、OCR.TesseractLanguage.French、OCR.TesseractLanguage.Italian
#   ImageFile [FileObject] 影像檔路徑 — 要擷取文字之影像的路徑
#   SearchMode [選項，預設 Whole] 搜尋模式 — OCR 作業的指定模式
#       可用值：OCR.SourceScanMode.Whole（整個指定來源）、OCR.SourceScanMode.SpecificSubregion（僅限特定子區域）、OCR.SourceScanMode.RegionRelativeToImage（與影像相關的子區域）
#   LanguageAbbreviation [文字]
#   LanguageDataPath [FolderObject]
#   Images [List<PngEncodedImage>] 影像 — 用於將掃描縮小至與指定影像相關之子區域的影像
#   ImageWidthMultiplier [整數，預設 1]
#   Tolerance [整數，預設 10] 容許度 — 指定特定影像與原始影像的差異程度。對於基本影像比對演算法，推薦容錯為 10，進階為 4。
#   ImageHeightMultiplier [整數，預設 1]
#   X1 [Nullable<Int32>] X1 — 用於縮小掃描範圍子區域起始點的 X 座標
#   X2 [Nullable<Int32>] X2 — 用於縮小掃描範圍子區域結束點的 X 座標
#   Y1 [Nullable<Int32>] Y1 — 用於縮小掃描範圍子區域起始點的 Y 座標
#   Y2 [Nullable<Int32>] Y2 — 用於縮小掃描範圍子區域結束點的 Y 座標
#   WaitForImage [布林，預設 True] 等待影像出現 — 指定是否等待影像顯示在畫面上或前景視窗中
#   Timeout [整數，預設 5] 逾時 — 指定在動作失敗前，等候作業完成的時間
#   SearchAlgorithm [選項，預設 Legacy] 影像比對演算法 — 選取搜尋影像時要使用的搜尋演算法。
#       可用值：OCR.ImageFinderAlgorithm.Legacy（基本）、OCR.ImageFinderAlgorithm.Template（進階）
# 產生的變數：
#   OcrText [文字] OCR 文字 — 文字擷取的結果
# 可能的錯誤：ExtractTextWithOCRError、ImageFileNotFoundError、LandmarkImageNotFoundError、GetTextFromScreenInNonInteractiveModeError、CreateOCREngineError、DataPathFolderNotFoundError、LanguageNotInstalledError、OCREngineNotAliveError
