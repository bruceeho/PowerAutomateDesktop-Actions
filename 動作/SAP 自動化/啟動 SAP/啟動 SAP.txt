# ==================== 說明 ====================
# 動作：啟動 SAP  (SAP.SapLogin)
# 英文名稱：Launch SAP
# 用途：正在啟動 SAP GUI 應用程式並連線至 SAP 系統。
# 位置：SAP 自動化
# 輸入參數：
#   ConnectionMode [選項，預設 Description] 連線模式 — 指定如何連線至 SAP GUI 伺服器。
#       可用值：SAP.ConnectionMode.Description（伺服器描述）、SAP.ConnectionMode.ConnectionString（伺服器連接字串）
#   LoginMode [選項，預設 Normal] 登入模式 — 指定如何登入 SAP GUI 伺服器，是手動輸入使用者名稱和密碼，還是使用單一登入 (SSO) 來登入伺服器。
#       可用值：SAP.LoginMode.Normal（手動登入 ）、SAP.LoginMode.SSO（單一登入 (SSO)）
#   Description [文字] 伺服器描述 — 指定連線的 SAP 系統名稱或 IP 位址。
#   Server [文字] 連接字串 — 指定 SAP GUI 伺服器的連線字串。連線字串為用以指定伺服器名稱、系統編號和其他連線詳細資料的唯一識別碼。
#   Client [文字] 用戶端 — 指定連線的 SAP 用戶端編號。
#   Username [文字] 使用者名稱 — 指定登入用的 SAP 使用者識別碼。
#   Password [文字(可加密)] 密碼 — 指定登入用的 SAP 使用者密碼。
#   Language [文字] 語言 — 指定使用者介面的 SAP 登入語言。
#   LogInOption [選項，預設 Terminate] 多重登入選項 — 多重登入選項會指示當使用者在已經登入的情況下嘗試登入時，SAP 系統的行為方式。
#       可用值：SAP.SapLogInOption.Single（繼續進行此登入，並結束其他登入）、SAP.SapLogInOption.Multiple（繼續進行此登入，但不結束系統中的其他登入）、SAP.SapLogInOption.Terminate（終止此登入）
# 產生的變數：
#   SapInstance [SapInstanceHandle] SAP 執行個體 — 要用於 SAP 自動化動作的 SAP 執行個體。SAP 執行個體指特定的 SAP 視窗。
#   OtherSapLoginTerminated [布林] 其他 SAP 登入已終止 — 是否終止其他 SAP 登入
#   CurrentSapLoginTerminated [布林] 指示目前的登入嘗試是否已終止。 — 是否終止正在以特定動作執行的 SAP 登入
# 可能的錯誤：SAPLoginActionError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。

# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
