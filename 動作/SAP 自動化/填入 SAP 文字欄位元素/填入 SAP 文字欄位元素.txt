# ==================== 說明 ====================
# 動作：填入 SAP 文字欄位元素  (SAP.PopulateTextField)
# 英文名稱：Populate SAP text field element  
# 用途：填入 SAP 視窗的 SAP 文字欄位元素。
# 位置：SAP 自動化
# 輸入參數：
#   SapInstance [SapInstanceHandle] SAP 執行個體 — 選取保存您要使用的 SAP 執行個體的變數。此變數應已定義在先前的 SAP 登入動作中。
#   ElementId [文字] SAP 元素識別碼 — SAP 元素的識別碼。此參數決定了 SAP 中將與動作互動的 UI 元素。您可以使用下方的按鈕在 SAP 畫面中指定 SAP UI 元素，或手動插入值。
#   TextValue [文字] 要填入的文字 — 要填入 SAP 文字欄位的文字。
#   PopulateTextFieldMode [選項，預設 Replace] 如果欄位不是空白 — 指定是要取代現有內容還是附加內容。
#       可用值：SAP.PopulateTextFieldMode.Replace（取代文字）、SAP.PopulateTextFieldMode.Append（附加文字）
# 可能的錯誤：PopulateTextFieldActionError

# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
