# ==================== 說明 ====================
# 動作：點選 SAP UI 元素  (SAP.ClickSapGuiElement)
# 英文名稱：Click SAP UI element
# 用途：透過對 SAP 視窗上任何 UI 元素的點選動作互動。
# 位置：SAP 自動化
# 輸入參數：
#   SapInstance [SapInstanceHandle] SAP 執行個體 — 選取保存您要使用的 SAP 執行個體的變數。此變數應已定義在先前的 SAP 登入動作中。
#   SapElementType [選項，預設 BasicSapElement] 元素類型 — 選取您需要互動的 SAP 元素類型。「按一下 SAP 元素」選項會對按鈕、選項按鈕、索引標籤、文字欄位、樹狀結構等 SAP 元素執行點選動作。
#       可用值：SAP.SapElementType.BasicSapElement（基本 SAP 元素）、SAP.SapElementType.CheckBox（核取方塊）、SAP.SapElementType.SapLabel（標籤）、SAP.SapElementType.SapComboBox（下拉式清單）、SAP.SapElementType.SapGridElement（格線元素）
#   ElementId [文字] SAP 元素識別碼 — SAP 元素的識別碼。此參數決定了 SAP 中將與動作互動的 UI 元素。您可以使用下方的按鈕，在 SAP 畫面中指定 SAP UI 元素，或手動插入值。
#   SapLabelAction [選項，預設 Expand] SAP 標籤作業 — 指定要展開、摺疊還是點選 SAP 標籤。
#       可用值：SAP.SapLabelAction.Expand（展開）、SAP.SapLabelAction.Collapse（摺疊）、SAP.SapLabelAction.Choose（選擇）
#   SapCheckBoxAction [選項，預設 Check] 將 SAP 核取方塊狀態設定為 — 指定核取方塊將變成已核取或未核取。
#       可用值：SAP.SapCheckBoxAction.Check（已勾選）、SAP.SapCheckBoxAction.Uncheck（未勾選）
#   ComboboxValue [文字] 下拉式選項值 — 將選取「指定下拉式選項」。
#   SapGridElementType [選項，預設 Normal] SAP 格線元素 — 選擇需要互動的 SAP 格線元素類型。
#       可用值：SAP.SapGridElementType.Normal（儲存格）、SAP.SapGridElementType.Row（列）、SAP.SapGridElementType.Header（標題）、SAP.SapGridElementType.ValueList（清單）、SAP.SapGridElementType.Button（按鈕）、SAP.SapGridElementType.ToolbarButton（工具列按鈕）、SAP.SapGridElementType.Checkbox（核取方塊）、SAP.SapGridElementType.RadioButton（選項按鈕）
# 可能的錯誤：ClickSapGuiElementActionError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
