SAP.CloseSapConnection SapInstance: `` CloseSapLogonOnLastConnection: True

# ==================== 說明 ====================
# 動作：關閉 SAP 連線  (SAP.CloseSapConnection)
# 英文名稱：Close SAP connection
# 用途：關閉所選 SAP 執行個體的 SAP 連線。請注意，與特定連線相關的所有執行個體都將終止。
# 位置：SAP 自動化
# 輸入參數：
#   SapInstance [SapInstanceHandle] SAP 執行個體 — 選取保存您要使用的 SAP 執行個體的變數。此變數應已定義在先前的 SAP 登入動作中。
#   CloseSapLogonOnLastConnection [布林，預設 True] 最後一個連線時關閉 SAP 登入視窗 — 如果無其他連線使用中，將關閉 SAP 登入視窗。
# 可能的錯誤：CloseSapConnectionActionError
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
# 來源：從本機 PAD 模組 DLL 自動擷取
