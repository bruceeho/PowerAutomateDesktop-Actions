# ==================== 說明 ====================
# 動作：選取 SAP 瀏覽項目  (SAP.SelectNavigationBarItem)
# 英文名稱：Select SAP navigation item
# 用途：在 SAP 視窗的應用程式工具列中選擇 SAP 選單項目。
# 位置：SAP 自動化
# 輸入參數：
#   SapInstance [SapInstanceHandle] SAP 執行個體 — 要用於 SAP 自動化動作的 SAP 執行個體。SAP 執行個體指特定的 SAP 視窗。
