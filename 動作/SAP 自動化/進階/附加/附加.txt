# 【模式 AttachToRunningSapByWindowTitle】根據標題將 SAP 視窗附加至執行個體。
SAP.AttachToRunning.AttachToRunningSapByWindowTitle SapInstance=> SapInstance

# 【模式 AttachToRunningSapByActiveSession】附加位於前景的 SAP 視窗。
SAP.AttachToRunning.AttachToRunningSapByActiveSession SapInstance=> SapInstance

# ==================== 說明 ====================
# 動作：附加  (SAP.AttachToRunning)
# 英文名稱：Attach
# 用途：將執行中 SAP GUI 應用程式附加至 SAP 執行個體。
# 位置：SAP 自動化 > 進階
# 輸入參數：
#   AttachMode [選項，預設 WindowTitle] 附加模式 — 指定將 SAP 執行個體附加至視窗的模式。如果選取 [前景或上次啟動] 選項，則 SAP 執行個體將附加至前景中的 SAP 工作階段。如果前景中沒有 SAP 工作階段，則執行個體將附加至已啟動且尚未關閉的上一個 SAP 工作階段。
#       可用值：SAP.AttachMode.Active（前景或上次啟用）、SAP.AttachMode.WindowTitle（視窗標題）
#   WindowTitle [文字，選填] 視窗標題 — 指定將附加執行個體的 SAP 視窗的標題。這可以從現有 SAP 工作階段的下拉式清單選取，或手動輸入。
# 產生的變數：
#   SapInstance [SapInstanceHandle] SAP 執行個體 — 要用於 SAP 自動化動作的 SAP 執行個體。SAP 執行個體指特定的 SAP 視窗。
# 可能的錯誤：AttachToRunningSapActionError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
