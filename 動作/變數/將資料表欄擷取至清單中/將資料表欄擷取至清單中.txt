# ==================== 說明 ====================
# 動作：將資料表欄擷取至清單中  (Variables.RetrieveDataTableColumnIntoList)
# 英文名稱：Retrieve data table column into list
# 用途：將資料表欄的內容轉換成清單
# 位置：變數
# 輸入參數：
#   DataTable [資料表] 資料表 — 包含要轉換成清單之欄的資料表
#   ColumnNameOrIndex [文字] 欄名稱或索引 — 欄名稱 (如有定義欄名稱)，或是要擷取之欄的索引編號
# 產生的變數：
#   ColumnAsList [List<Object>] 清單形式的欄內容 — 包含所指定資料表內容的新清單
# 可能的錯誤：ColumnNameNotFoundError、ColumnIndexOutOfRangeError
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
