# ==================== 說明 ====================
# 動作：剖析文字  (Text.ParseText)
# 英文名稱：Parse text
# 用途：剖析文字以找出指定的子文字或規則運算式模式第一次或所有出現的位置。
# 位置：文字
# 輸入參數：
#   Text [文字] 要剖析的文字 — 要剖析的文字
#   TextToFind [文字] 要尋找的文字 — 要搜尋的子文字或規則運算式
#   IsRegEx [布林，預設 False] 是規則運算式 — 指定子文字是否為規則運算式。例如 \d 表示子文字可以是任何數字
#   StartingPosition [整數，預設 0] 於此位置開始剖析 — 開始尋找「要尋找的文字」的位置。第一個位置是零，請使用 0 從頭開始尋找
#   FirstOccurrenceOnly [布林，預設 True] 僅第一次出現的位置 — 指定只要尋找第一次出現的位置，或是找出「要尋找的文字」每一次出現的位置
#   IgnoreCase [布林，預設 False] 忽略大小寫 — 指定要使用區分大小寫或不區分大小寫的比對方式來尋找指定的文字
# 產生的變數：
#   Match [文字] 相符項目 — 符合所指規則運算式的結果
#   Matches [List<String>] 相符 — 符合所指規則運算式的結果
#   OccurrencePositions [List<Int32>] 找到文字的位置 — 『要尋找的文字』在『要解析的文字』中的位置。計數從 0 開始，意即第一個位置是 0，如果未找到文字，則預期值為 -1
#   OccurrencePosition [整數] 找到文字的位置 — 『要尋找的文字』在『要解析的文字』中的位置。計數從 0 開始，意即第一個位置是 0，如果未找到文字，則預期值為 -1。
