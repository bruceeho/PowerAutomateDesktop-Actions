# ==================== 說明 ====================
# 動作：等待快速鍵  (MouseAndKeyboard.WaitForShortcutKey)
# 英文名稱：Wait for shortcut key
# 用途：暫停流程執行，直到按下特定的快速鍵。快速鍵必須只包含一個鍵，或一個鍵和 (Ctrl、Alt、Shift) 組合。可定義多個快速鍵。

# 輸入參數：

# 產生的變數：
#   IndexOfShortcutKeyPressed [整數] 快速鍵的索引 — 快速鍵的索引 (如果快速鍵為清單格式)。
