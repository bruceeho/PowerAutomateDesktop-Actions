PDF.ExtractPages PDFFile: `` PageSelection: `` ExtractedPDFPath: `` IfFileExists: PDF.IfFileExists.AddSequentialSuffix ExtractedPDFFile=> ExtractedPDFFile

# ==================== 說明 ====================
# 動作：將 PDF 檔案中的頁面擷取至新的 PDF 檔案  (PDF.ExtractPages)
# 英文名稱：Extract PDF file pages to new PDF file
# 用途：將 PDF 檔案中的頁面擷取至新的 PDF 檔案
# 位置：PDF
# 輸入參數：
#   PDFFile [FileObject] PDF 檔案 — 要擷取頁面的 PDF 檔案。請輸入檔案路徑，或是包含檔案或文字路徑的變數
#   Password [文字(可加密)，選填] 密碼 — PDF 檔案的密碼。如果 PDF 未以密碼保護，請保留空白
#   PageSelection [文字] 頁面選擇 — 要保留的頁面索引號碼 (例如 1、3、17-24)
#   ExtractedPDFPath [FileObject] 已擷取的 PDF 檔案路徑 — 儲存已擷取 PDF 檔案的路徑
#   IfFileExists [選項，預設 AddSequentialSuffix] 如果檔案已存在 — 指定當輸出 PDF 檔案已經存在時應採取的行動
#       可用值：PDF.IfFileExists.Overwrite（覆寫）、PDF.IfFileExists.DoNotModifyFiles（不要覆寫）、PDF.IfFileExists.AddSequentialSuffix（新增循序尾碼）
# 產生的變數：
#   ExtractedPDFFile [FileObject] 已擷取的 PDF 檔案 — 新的 PDF 檔案
# 可能的錯誤：InvalidPasswordError、PDFFileDoesNotExistError、PageOutOfBoundsError、InvalidPageSelectionError、FailedToExtractNewPDFFileError
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
# 來源：從本機 PAD 模組 DLL 自動擷取
