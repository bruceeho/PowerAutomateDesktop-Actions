# ==================== 說明 ====================
# 動作：合併 PDF 檔案  (PDF.MergeFiles)
# 英文名稱：Merge PDF files
# 用途：將多個 PDF 檔案合併為一個新檔案
# 位置：PDF
# 輸入參數：
#   PDFFiles [List<FileObject>] PDF 檔案 — 要合併的檔案。將多個檔案放在雙引號 (") 中，並以分隔符號隔開，或使用檔案清單
#   MergedPDFPath [FileObject] 合併的 PDF 路徑 — 儲存合併之 PDF 檔案的路徑
#   IfFileExists [選項，預設 AddSequentialSuffix] 如果檔案已存在 — 指定當目的地檔案已經存在時應採取的行動
#       可用值：PDF.IfFileExists.Overwrite（覆寫）、PDF.IfFileExists.DoNotModifyFiles（不要覆寫）、PDF.IfFileExists.AddSequentialSuffix（新增循序尾碼）
#   Passwords [文字(可加密)，選填] 密碼 — 帶分隔符號的密碼。順序應該與輸入 PDF 的順序相同。如果 PDF 未以密碼保護，請保留空白
#   PasswordDelimiter [文字，預設 ,] 分隔符號 — 自訂密碼分隔符號。此分隔符號不應該是任何密碼的組成部分
# 產生的變數：
#   MergedPDF [FileObject] 合併的 PDF 檔案 — 合併的 PDF 檔案
# 可能的錯誤：PDFFileDoesNotExistError、InvalidPasswordError、FailedToMergePDFFilesError
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
