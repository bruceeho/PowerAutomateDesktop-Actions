# ==================== 說明 ====================
# 動作：處理 Exchange 電子郵件訊息  (Exchange.ProcessExchangeMessages)
# 英文名稱：Process Exchange email messages
# 用途：將電子郵件訊息 (或電子郵件訊息清單) 移動、刪除或標示為未讀取
# 位置：Exchange Server
# 輸入參數：
#   Connection [ExchangeConnectionHandle] Exchange 連線 — Exchange 連線。使用「連線至 Exchange Server」動作建立 Exchange 連線
#   EmailsToProcess [List<ExchangeMailMessage>] 要處理的電子郵件訊息 — 要處理的電子郵件訊息。使用透過「擷取 Exchange 電子郵件訊息」動作填入的變數
#   Operation [選項，預設 Move] 作業 — 指定要在指定的電子郵件訊息上執行的作業
#       可用值：Exchange.ProcessEmailOperation.Delete（從伺服器刪除電子郵件訊息）、Exchange.ProcessEmailOperation.MarkAsUnread（將電子郵件訊息標示為未讀取）、Exchange.ProcessEmailOperation.Move（將電子郵件訊息移至郵件資料夾）
#   MailboxType [選項，預設 Personal] 信箱類型 — 要從中擷取電子郵件訊息的信箱類型
#       可用值：Exchange.MailboxType.Personal（個人）、Exchange.MailboxType.Shared（共用）
#   SharedMailboxAddress [文字] 共用信箱地址 — 要從中擷取電子郵件訊息的共用信箱地址
#   MoveToCustomFolder [布林，預設 False] 移至自訂資料夾 — 指定要將電子郵件訊息移至自訂資料夾或預先定義的 Exchange 資料夾
#   MailFolder [文字，預設 Inbox] 郵件資料夾 — 要將電子郵件訊息移至其中的郵件資料夾名稱或路徑 (例如 folder1\folder2)
#   ExchangeFolder [選項，預設 Inbox] Exchange 資料夾 — 要從中移出電子郵件訊息的預先定義 Exchange 資料夾
#       可用值：Exchange.Folder.Inbox（收件匣）、Exchange.Folder.DeletedItems（刪除的項目）、Exchange.Folder.Drafts（草稿）、Exchange.Folder.Outbox（寄件匣）、Exchange.Folder.SentItems（寄件備份）、Exchange.Folder.JunkEmail（垃圾電子郵件）
# 可能的錯誤：MailFolderNotFoundError、ProcessEmailMessagesError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
