# ==================== 說明 ====================
# 動作：取得視窗中選取的核取方塊  (UIAutomation.GetSelectedCheckboxesInWindow)
# 英文名稱：Get selected checkboxes in window
# 用途：擷取核取方塊群組中所選取核取方塊的名稱，或特定核取方塊的狀態
# 位置：使用者介面自動化 > 資料擷取
# 輸入參數：
#   Control [UIControl] UI 元素 — 核取方塊或核取方塊群組
#   Operation [選項，預設 GetSelectedCheckboxesInGroup] 作業 — 指定要擷取選取的多個核取方塊的狀態，或只擷取一個
#       可用值：UIAutomation.CheckboxesScanMode.GetSelectedCheckboxesInGroup（取得群組中所選取核取方塊的名稱）、UIAutomation.CheckboxesScanMode.GetStateOfCheckbox（取得核取方塊的狀態）
#   BringToFront [布林，預設 True] 移到最上層 — 指定在執行期間是否應將包含 UI 元素的視窗放在最上層。如果停用此選項，動作將在背景執行。請注意，並非所有 UI 元素都與停用該選項相容。此外，如果執行動作需要捲動，停用此選項可能無法擷取所有元素。
# 產生的變數：
#   CheckboxState [布林] 核取方塊狀態 — 所選取核取方塊的狀態
#   SelectedCheckboxes [List<String>] 選取的核取方塊名稱 — 指定的核取方塊群組內所選取核取方塊的名稱
