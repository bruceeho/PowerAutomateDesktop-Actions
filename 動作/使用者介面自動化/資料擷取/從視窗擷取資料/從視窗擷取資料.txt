# 【模式 ExtractDataInExcelSpreadsheet】從 Excel 試算表中某個視窗的特定部分擷取資料
UIAutomation.ExtractDataFromWindow.ExtractDataInExcelSpreadsheet Control: `` BringToFront: True ExcelInstance=> ExcelInstance

# ==================== 說明 ====================
# 動作：從視窗擷取資料  (UIAutomation.ExtractDataFromWindow)
# 英文名稱：Extract data from window
# 用途：從視窗的特定部分擷取單一值、清單或資料表形式的資料
# 位置：使用者介面自動化 > 資料擷取
# 輸入參數：
#   Control [UIControl] 視窗 — 要從中擷取資料的視窗
#   StoreExtractedDataIn [選項，預設 ExcelSpreadsheet] 將擷取的資料儲存在 — 指定要儲存擷取資料的位置
#       可用值：UIAutomation.StoreExtractedDataIn.ExcelSpreadsheet（Excel 試算表）、UIAutomation.StoreExtractedDataIn.Variable（變數）
#   BringToFront [布林，預設 True] 移到最上層 — 指定在執行期間是否應將包含 UI 元素的視窗放在最上層。如果停用此選項，動作將在背景執行。請注意，並非所有 UI 元素都與停用該選項相容。此外，如果執行動作需要捲動，停用此選項可能無法擷取所有元素。
# 產生的變數：
#   ExcelInstance [ExcelInstanceHandle] Excel 執行個體 — 包含所擷取資料的 Excel 執行個體。使用這個執行個體可透過 Excel 專屬動作操控試算表 (或儲存後將它關閉)。
#   ExtractedData [一般值] 擷取的資料 — 資料表形式的擷取資料
# 可能的錯誤：ExtractWindowDataError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
