# ==================== 說明 ====================
# 動作：設定視窗可見度  (UIAutomation.SetWindowVisibility)
# 英文名稱：Set window visibility
# 用途：顯示隱藏的視窗或隱藏可見的視窗
# 位置：使用者介面自動化 > 視窗
# 輸入參數：
#   FindWindowMode [選項，預設 Control] 尋找視窗模式 — 指定要使用 UI 元素或視窗標題/類別組合尋找視窗
#       可用值：UIAutomation.FindWindowBy.Control（透過視窗 UI 元素）、UIAutomation.FindWindowBy.InstanceOrHandle（透過視窗執行個體/控點）、UIAutomation.FindWindowBy.TitleAndClass（透過標題和/或類別）
#   Control [UIControl]
#   WindowInstance [整數] 視窗執行個體 — 要設定可見度之視窗的執行個體或控點
#   Title [文字，選填] 視窗標題 — 視窗標題。可使用萬用字元，如 '?' 或 '*'。
#   Class [文字，選填] 視窗類別 — 如果有兩個標題相同的視窗，則視窗類別有助於區分兩者。在這種情況下，請輸入要使用的視窗類別。
#   Visibility [選項，預設 Hidden] 可見度 — 選擇要設定的視窗可見度狀態
#       可用值：UIAutomation.Visibility.Visible（可見）、UIAutomation.Visibility.Hidden（隱藏）
# 可能的錯誤：WindowNotFoundError、SetWindowVisibilityError、WindowOperationInNonInteractiveModeError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
