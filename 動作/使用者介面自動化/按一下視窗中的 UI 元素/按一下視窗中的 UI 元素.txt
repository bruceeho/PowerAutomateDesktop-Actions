# 輸入參數：
#   ClickType [選項，預設 LeftClick] 按一下類型 — 要執行的點擊類型
#       可用值：UIAutomation.ClickType.LeftClick（按滑鼠左鍵）、UIAutomation.ClickType.RightClick（按滑鼠右鍵）、UIAutomation.ClickType.DoubleClick（按兩下）、UIAutomation.ClickType.LeftButtonDown（左鍵按下）、UIAutomation.ClickType.LeftButtonUp（左鍵放開）、UIAutomation.ClickType.RightButtonDown（右鍵按下）、UIAutomation.ClickType.RightButtonUp（右鍵放開）、UIAutomation.ClickType.MiddleClick（按滑鼠中間鍵）
#   MousePositionRelativeToElement [選項，預設 MiddleCenter] 相對於 UI 元素的滑鼠位置 — 指定要在按一下之前先將滑鼠移至哪一個 UI 元素區段

#   Simulate [布林，預設 False] 模擬動作 — 指定在點擊前是否模擬滑鼠游標在元素上的移動。此選項不需要聚焦於 UI 元素的畫面，它不會自動將其帶入前景。請注意，此選項僅適用於左鍵點擊動作，而且可能不適用於所有 UI 元素。
