# 動作：如果影像  (UIAutomation.IfImageAction)
# 英文名稱：If image
# 用途：此動作標記根據畫面上是否找到所選取影像的條件式動作區塊的開頭
# 位置：使用者介面自動化
# 輸入參數：
#   CheckMode [選項，預設 Exists]
#       可用值：UIAutomation.IfImageExists.Exists（存在）、UIAutomation.IfImageExists.DoesNotExist（不存在）
#   Images [List<PngEncodedImage>]
#   SearchForImageOn [選項，預設 EntireScreen]
#       可用值：UIAutomation.SearchTarget.EntireScreen（整個畫面）、UIAutomation.SearchTarget.ForegroundWindow（僅前景視窗）
#   SearchMode [選項，預設 Whole]
#       可用值：UIAutomation.SearchMode.Whole（搜尋整個畫面或前景視窗）、UIAutomation.SearchMode.Subregion（在指定的畫面或前景視窗子區域搜尋）
#   FindAllImages [布林，預設 False]
#   X1 [Nullable<Int32>]
#   X2 [Nullable<Int32>]
#   Y1 [Nullable<Int32>]
#   Y2 [Nullable<Int32>]
#   Tolerance [整數，預設 10]
#   SearchAlgorithm [選項，預設 Legacy]
#       可用值：UIAutomation.ImageFinderAlgorithm.Legacy（基本）、UIAutomation.ImageFinderAlgorithm.Template（進階）
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
