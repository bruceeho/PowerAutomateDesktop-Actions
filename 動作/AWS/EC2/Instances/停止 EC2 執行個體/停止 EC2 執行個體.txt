# ==================== 說明 ====================
# 動作：停止 EC2 執行個體  (AWS.StopEC2Instance)
# 英文名稱：Stop EC2 instance
# 用途：停止 EC2 執行個體
# 位置：AWS > EC2 > Instances
# 輸入參數：
#   Ec2Client [Ec2ClientObject] EC2 用戶端 — EC2 用戶端
#   InstanceIds [List<String>] 執行個體識別碼 — 要停止的執行個體識別碼
#   Force [布林，預設 False] 強制停止 — 指定是否要強制執行個體停止。執行個體沒有機會可以排清檔案系統快取或檔案系統中繼資料
#   Hibernate [布林，預設 False] 休眠:  — 指定如果執行個體啟動時已啟用休眠，是否要讓執行個體休眠。如果執行個體無法順利休眠，就會發生正常關機
# 產生的變數：
#   StoppingEc2Instances [List<InstanceStateChange>] 正在停止執行個體 — 已停止執行個體的傳回資訊
# 可能的錯誤：AuthenticationFailureError、UnauthorizedOperationError、UnsupportedOperationError、InvalidInstanceIdError、RequestFailedError
