# ==================== 說明 ====================
# 動作：前往網頁  (WebAutomation.GoToWebPage)
# 英文名稱：Go to web page
# 用途：瀏覽網頁瀏覽器至新頁面
# 位置：瀏覽器自動化
# 輸入參數：
#   BrowserInstance [WebBrowserInstanceHandle] 網頁瀏覽器執行個體 — 輸入或選擇包含要使用的網頁瀏覽器執行個體的變數
#   NavigationType [選項，預設 NavigateToUrl] 瀏覽 — 指定要瀏覽的目標位置
#       可用值：WebAutomation.NavigationType.NavigateToUrl（至 URL）、WebAutomation.NavigationType.NavigateBack（向後）、WebAutomation.NavigationType.NavigateForward（向前）、WebAutomation.NavigationType.ReloadWebPage（重新載入網頁）
#   Url [文字] URL — 輸入要瀏覽的目標 URL
#   WaitForPageToLoad [布林，預設 True] 等待頁面載入 — 指定是否要等待網頁完整載入再繼續進行
#   WaitForPageToLoadTimeout [整數，預設 60] 網頁載入逾時 — 設定動作擲回錯誤之前的頁面載入時間，以秒為單位
#   HandleDialogAction [選項，預設 DoNothing] 如果快顯對話方塊出現 — 指定若載入網頁時出現快顯對話方塊，要執行的操作
#       可用值：WebAutomation.HandleDialogAction.CloseIt（關閉它）、WebAutomation.HandleDialogAction.PressButton（按下按鈕）、WebAutomation.HandleDialogAction.DoNothing（不執行任何動作）
#   DialogButton [文字，預設 OK] 要按下的對話方塊按鈕 — 輸入快顯對話方塊出現時要按下的對話方塊按鈕
# 可能的錯誤：NavigateToWebPageError、InvalidUrlError
