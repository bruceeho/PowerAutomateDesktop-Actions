# ==================== 說明 ====================
# 動作：啟動新的 Microsoft Edge  (WebAutomation.LaunchEdge)
# 英文名稱：Launch new Microsoft Edge
# 用途：啟動新執行個體或附加至 Microsoft Edge 的執行中執行個體，讓網站和 Web 應用程式自動化
# 位置：瀏覽器自動化
# 輸入參數：
#   LaunchMode [選項，預設 LaunchNew] 啟動模式 — 指定要啟動新的 Microsoft Edge 執行個體，或附加至現有執行個體
#       可用值：WebAutomation.LaunchMode.LaunchNew（啟動新執行個體）、WebAutomation.LaunchMode.Attach（附加至執行中的執行個體）
#   AttachMode [選項，預設 ByTitle] 附加至 Microsoft Edge 索引標籤 — 指定要依標題、URL 附加至 Microsoft Edge 索引標籤，或附加至做為前景視窗執行的 Microsoft Edge 使用中索引標籤
#       可用值：WebAutomation.AttachMode.ByTitle（依標題）、WebAutomation.AttachMode.ByUrl（依 URL）、WebAutomation.AttachMode.ForegroundWindow（使用前景視窗）
#   Url [文字] 初始 URL — 輸入網頁瀏覽器啟動時要前往的網站 URL
#   WindowState [選項，預設 Normal] 視窗狀態 — 指定要以標準、最小化或最大化狀態啟動瀏覽器視窗
#       可用值：WebAutomation.BrowserWindowState.Normal（標準）、WebAutomation.BrowserWindowState.Maximized（已最大化）、WebAutomation.BrowserWindowState.Minimized（已最小化）
#   TabTitle [文字] 索引標籤標題 — 輸入要做為附加目標的 Microsoft Edge 索引標籤標題 (或其中一部分)
#   TabUrl [文字] 索引標籤 URL — 輸入要做為附加目標的 Microsoft Edge 索引標籤 URL (或其中一部分)
#   ClearCache [布林，預設 False] 清除快取 — 指定是否要在啟動網頁瀏覽器後，隨即完整清除其快取
#   ClearCookies [布林，預設 False] 清除 Cookie — 指定是否要在啟動網頁瀏覽器後，隨即清除當中儲存的所有 Cookie
#   WaitForPageToLoad [布林，預設 True] 等待頁面載入 — 指定是否要等待新網頁完整載入再繼續進行
#   WaitForPageToLoadTimeout [整數，預設 60] 網頁載入逾時 — 設定動作擲回錯誤之前的頁面載入時間，以秒為單位
#   HandleDialogAction [選項，預設 DoNothing] 如果快顯對話方塊出現 — 指定若載入初始網頁時出現快顯對話方塊，要執行的操作
#       可用值：WebAutomation.HandleDialogAction.CloseIt（關閉它）、WebAutomation.HandleDialogAction.PressButton（按下按鈕）、WebAutomation.HandleDialogAction.DoNothing（不執行任何動作）
#   DialogButton [文字，預設 OK] 要按下的對話方塊按鈕 — 輸入快顯對話方塊出現時要按下的對話方塊按鈕
#   Timeout [整數，預設 60] 逾時 — 設定您想要等候瀏覽器啟動的時間 (秒鐘)，在此時間過後，此動作即失敗
#   AttachTimeout [整數，預設 5] 逾時 — 設定在動作失敗之前您希望等待瀏覽器連結的時間 (以秒為單位)
#   CommunicationMode [選項，預設 Extension] 瀏覽器互動方式 — 選擇流程執行期間瀏覽器互動的方法。瀏覽器延伸選項需要安裝附加元件，並支援自動設定檔登入。或者，選擇 WebDriver 會直接連接到瀏覽器，但不支援自動設定檔登入。
#       可用值：WebAutomation.BrowserCommunicationMethod.Extension（瀏覽器延伸）、WebAutomation.BrowserCommunicationMethod.WebDriver（WebDriver）
#   PiPUserDataFolderMode [選項，預設 AutomaticProfile] 使用者資料的資料夾 — 指定當流程在 Picture-in-Picture 中執行時瀏覽器將使用的使用者資料夾。如果選取瀏覽器預設值，即無法同時在桌面和 Picture-in-Picture 中啟動瀏覽器。
#       可用值：WebAutomation.PiPUserDataFolderModeEnum.AutomaticProfile（Picture-in-picture 預設值）、WebAutomation.PiPUserDataFolderModeEnum.DefaultProfile（瀏覽器預設值）、WebAutomation.PiPUserDataFolderModeEnum.CustomProfile（自訂）
#   PiPUserDataFolderPath [FolderObject] 使用者資料的資料夾路徑 — 指定當流程在 Picture-in-Picture 中執行時瀏覽器將使用的使用者資料夾路徑。
#   TargetDesktop [文字，預設 {"DisplayName":"Local Computer","Route":{"ServerType":"Local","ServerAddress":""}}] 目標桌面連接字串 — 設定瀏覽器要啟動的目標桌面的連接字串。
# 產生的變數：
#   BrowserInstance [WebBrowserInstanceHandle] Microsoft Edge 執行個體 — 要用於 Web 自動化動作的 Microsoft Edge 執行個體
# 可能的錯誤：LaunchEdgeError、InvalidUrlError

# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
