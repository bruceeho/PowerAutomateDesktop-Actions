# ==================== 說明 ====================
# 動作：啟動新的 Internet Explorer  (WebAutomation.LaunchInternetExplorer)
# 英文名稱：Launch new Internet Explorer
# 用途：啟動新執行個體或附加至 Internet Explorer 的執行中執行個體，讓網站和 Web 應用程式自動化
# 位置：瀏覽器自動化
# 輸入參數：
#   LaunchMode [選項，預設 LaunchNewAutomationBrowser] 啟動模式 — 指定要啟動自動化瀏覽器或新的 Internet Explorer 執行個體，或附加至現有執行個體
#       可用值：WebAutomation.InternetExplorerLaunchMode.LaunchNewAutomationBrowser（啟動自動化瀏覽器）、WebAutomation.InternetExplorerLaunchMode.LaunchNewInternetExplorer（啟動新的 Internet Explorer）、WebAutomation.InternetExplorerLaunchMode.AttachToRunningInternetExplorer（附加至執行中的 Internet Explorer）
#   Url [文字] 初始 URL — 輸入網頁瀏覽器啟動時要前往的網站 URL
#   AttachMode [選項，預設 ByTitle] 附加至 Internet Explorer 索引標籤 — 指定要依標題、URL 附加至 Internet Explorer 索引標籤，或附加至做為前景視窗執行的 Internet Explorer 使用中索引標籤
#       可用值：WebAutomation.AttachMode.ByTitle（依標題）、WebAutomation.AttachMode.ByUrl（依 URL）、WebAutomation.AttachMode.ForegroundWindow（使用前景視窗）
#   TabUrl [文字] 索引標籤 URL — 輸入要做為附加目標的 Internet Explorer 索引標籤 URL (或其中一部分)
#   TabTitle [文字] 索引標籤標題 — 輸入要做為附加目標的 Internet Explorer 索引標籤標題 (或其中一部分)
#   WindowState [選項，預設 Normal] 視窗狀態 — 指定要以標準、最小化或最大化狀態啟動瀏覽器視窗
#       可用值：WebAutomation.BrowserWindowState.Normal（標準）、WebAutomation.BrowserWindowState.Maximized（已最大化）、WebAutomation.BrowserWindowState.Minimized（已最小化）
#   ClearCookies [布林，預設 False] 清除 Cookie — 指定是否要在啟動網頁瀏覽器後，隨即清除當中儲存的所有 Cookie
#   ClearCache [布林，預設 False] 清除快取 — 指定是否要在啟動網頁瀏覽器後，隨即完整清除其快取
#   WaitForPageToLoad [布林，預設 True] 等待頁面載入 — 指定是否要等待新網頁完整載入再繼續進行
#   WaitForPageToLoadTimeout [整數，預設 60] 網頁載入逾時 — 設定動作擲回錯誤之前的頁面載入時間，以秒為單位
#   HandleDialogAction [選項，預設 DoNothing] 如果快顯對話方塊出現 — 指定若載入初始網頁時出現快顯對話方塊，要執行的操作
#       可用值：WebAutomation.HandleDialogAction.CloseIt（關閉它）、WebAutomation.HandleDialogAction.PressButton（按下按鈕）、WebAutomation.HandleDialogAction.DoNothing（不執行任何動作）
#   DialogButton [文字，預設 OK] 要按下的對話方塊按鈕 — 輸入快顯對話方塊出現時要按下的對話方塊按鈕
#   CustomUserAgentString [文字，選填] 自訂使用者 Agent 字串 — 指定執行階段網頁協助程式的自訂使用者 Agent 字串。如果此欄位保留空白，則執行階段網頁協助程式會預設使用電腦上安裝的 Internet Explorer 的使用者 Agent 字串。
#   AttachTimeout [整數，預設 5] 逾時 — 設定在動作失敗之前您希望等待瀏覽器連結的時間 (以秒為單位)
#   TargetDesktop [文字，預設 {"DisplayName":"Local Computer","Route":{"ServerType":"Local","ServerAddress":""}}] 目標桌面連接字串 — 設定瀏覽器要啟動的目標桌面的連接字串。
# 產生的變數：
#   BrowserInstance [WebBrowserInstanceHandle] Internet Explorer 執行個體 — 要用於 Web 自動化動作的 Internet Explorer 執行個體
# 可能的錯誤：LaunchInternetExplorerError、InvalidUrlError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
