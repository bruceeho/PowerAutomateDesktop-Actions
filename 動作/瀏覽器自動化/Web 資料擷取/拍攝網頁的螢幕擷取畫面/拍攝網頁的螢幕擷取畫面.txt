# ==================== 說明 ====================
# 動作：拍攝網頁的螢幕擷取畫面  (WebAutomation.TakeScreenshot)
# 英文名稱：Take screenshot of web page
# 用途：拍攝瀏覽器中目前顯示網頁 (或網頁元素) 的螢幕擷取畫面，並將影像儲存至檔案或剪貼簿
# 位置：瀏覽器自動化 > Web 資料擷取
# 輸入參數：
#   BrowserInstance [WebBrowserInstanceHandle] 網頁瀏覽器執行個體 — 輸入或選擇包含要使用的網頁瀏覽器執行個體的變數
#   Operation [選項，預設 WebPage] 擷取 — 指定要擷取整個網頁或只擷取其中特定元素
#       可用值：WebAutomation.WebPageScreenshotOperation.WebPage（整個網頁）、WebAutomation.WebPageScreenshotOperation.Element（特定元素）
#   Control [WebControl] UI 元素 — 選取網頁上要擷取的 UI 元素
#   SaveMode [選項，預設 Clipboard] 儲存模式 — 指定要將影像儲存至檔案，或儲存至剪貼簿
#       可用值：WebAutomation.WebPageScreenshotSaveMode.Clipboard（剪貼簿）、WebAutomation.WebPageScreenshotSaveMode.File（檔案）
#   File [FileObject] 影像檔 — 設定要儲存影像擷取的檔案完整路徑
#   FileFormat [選項，預設 Bmp] 檔案格式 — 選取影像檔的格式
#       可用值：WebAutomation.FileFormat.Bmp（BMP）、WebAutomation.FileFormat.Gif（GIF）、WebAutomation.FileFormat.Jpg（JPG）、WebAutomation.FileFormat.Png（PNG）、WebAutomation.FileFormat.Tiff（TIFF）
# 可能的錯誤：ElementNotFoundError、SaveFileError、SaveToClipboardError、TakeScreenshotError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
