# ==================== 說明 ====================
# 動作：從網頁擷取資料  (WebAutomation.ExtractData)
# 英文名稱：Extract data from web page
# 用途：從網頁的特定部分擷取單一值、清單、資料列或資料表形式的資料
# 位置：瀏覽器自動化 > Web 資料擷取
# 輸入參數：
#   BrowserInstance [WebBrowserInstanceHandle] 網頁瀏覽器執行個體 — 輸入或選擇包含要使用的網頁瀏覽器執行個體的變數
#   ExtractionParameters [資料表] 擷取參數 — 擷取資料時要使用的參數。根據擷取模式而定，可接受不同的資料。
#   Control [文字] UI 元素 — 選取網頁上要從中擷取資料的 UI 元素
#   MaxWebPagesToProcess [整數] 要處理的網頁數目上限 — 要處理的網頁數目上限
#   UsePhysicalClick [布林，預設 False]
#   PagerCssSelector [文字] 頁面巡覽區 CSS 選取器 — 頁面巡覽區 CSS 選取器
#   ExtractionMode [選項，預設 SingleValue] 擷取模式 — 指定要從網頁擷取的內容
#       可用值：WebAutomation.ExtractionMode.Undefined（未定義）、WebAutomation.ExtractionMode.SingleValue（單一值）、WebAutomation.ExtractionMode.HandpickedValues（自選值）、WebAutomation.ExtractionMode.List（清單）、WebAutomation.ExtractionMode.Table（資料表）、WebAutomation.ExtractionMode.EntireHtmlTable（完整 HTML 表格）
#   UsePaging [布林，預設 False] 使用分頁 — 指定是否要使用分頁
#   GetAllWebPages [布林，預設 False] 取得所有網頁 — 指定是否取得所有網頁
#   StoreDataMode [選項，預設 Variable] 儲存資料模式 — 指定要將擷取的資料儲存於變數或 Excel 試算表中
#       可用值：WebAutomation.StoreDataMode.Variable（變數）、WebAutomation.StoreDataMode.ExcelSpreadsheet（Excel 試算表）
#   PostProcessData [布林，預設 False]
#   TimeoutInSeconds [整數，預設 60]
# 產生的變數：
#   ExcelInstance [ExcelInstanceHandle] Excel 執行個體 — 包含所擷取資料的 Excel 執行個體。使用這個執行個體可透過 Excel 專屬動作操控試算表 (或儲存後將它關閉)。
#   ExtractedData [資料表] 擷取的資料 — 以單一值、清單、資料列或資料表形式擷取的資料
# 可能的錯誤：ExtractDataError、LaunchExcelError、WriteToExcelError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
# 來源：從本機 PAD 模組 DLL 自動擷取
