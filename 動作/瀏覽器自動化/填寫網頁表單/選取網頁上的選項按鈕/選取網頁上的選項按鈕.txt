# ==================== 說明 ====================
# 動作：選取網頁上的選項按鈕  (WebAutomation.SelectRadioButton)
# 英文名稱：Select radio button on web page
# 用途：選取網頁上的選項按鈕
# 位置：瀏覽器自動化 > 填寫網頁表單
# 輸入參數：
#   BrowserInstance [WebBrowserInstanceHandle] 網頁瀏覽器執行個體 — 輸入或選擇包含要使用的網頁瀏覽器執行個體的變數
#   Control [WebControl] UI 元素 — 要選取的選項按鈕
#   WaitForPageToLoad [布林，預設 True] 等待頁面載入 — 指定選取選項按鈕後，是否要等待新網頁完整載入
#   WaitForPageToLoadTimeout [整數，預設 60] 網頁載入逾時 — 設定動作擲回錯誤之前的頁面載入時間，以秒為單位
#   HandleDialogAction [選項，預設 DoNothing] 如果快顯對話方塊出現 — 指定選取選項按鈕之後出現快顯對話方塊時要執行的操作
#       可用值：WebAutomation.HandleDialogAction.CloseIt（關閉它）、WebAutomation.HandleDialogAction.PressButton（按下按鈕）、WebAutomation.HandleDialogAction.DoNothing（不執行任何動作）
#   DialogButton [文字，預設 OK] 要按下的對話方塊按鈕 — 快顯對話方塊出現時要按下的對話方塊按鈕
# 可能的錯誤：ElementNotFoundError、SelectRadioButtonError
