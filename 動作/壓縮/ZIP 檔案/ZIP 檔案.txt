# ==================== 說明 ====================
# 動作：ZIP 檔案  (Compression.ZipFiles)
# 英文名稱：Zip files
# 用途：將一或多個檔案或資料夾壓縮至 ZIP 封存中
# 位置：壓縮
# 輸入參數：
#   ArchivePath [FileObject] 封存路徑 — 所要建立 ZIP 檔案的完整路徑。如果檔案已經存在，這個動作會將新的壓縮檔案新增至現有的 ZIP 檔案。如果 ZIP 檔案已經包含同名的檔案或資料夾，則會覆寫該同名項目。
#   FilesOrFoldersToZip [List<FileSystemObject>] 要壓縮的檔案 — 要包含於 ZIP 檔案中之檔案或資料夾的完整路徑
#   CompressionLevel [選項，預設 BestBalanceOfSpeedAndCompression] 壓縮等級 — 要使用的壓縮等級。壓縮等級越高，檔案就會越小，但建立或操作的時間會越長
#       可用值：Compression.CompressionLevel.None（無​​）、Compression.CompressionLevel.BestSpeed（最佳速度）、Compression.CompressionLevel.BestBalanceOfSpeedAndCompression（速度與壓縮的最佳平衡點）、Compression.CompressionLevel.BestCompression（最佳壓縮）
#   Password [文字(可加密)，選填] 密碼 — 用於保護 ZIP 的密碼。將此屬性保留空白，可建立不採用密碼保護的 ZIP
#   ArchiveComment [文字，選填] 封存註解 — 要包含在 ZIP 檔案中做為檔案屬性的註解
# 產生的變數：
#   ZipFile [FileObject] ZIP 檔案 — 由此動作建立的 ZIP 檔案
# 可能的錯誤：FileNotFoundError、InvalidFileError、ArchiveExistsInvalidError、ZipError
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
