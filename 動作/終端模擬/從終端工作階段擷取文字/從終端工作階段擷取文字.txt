# 英文名稱：Get text from terminal session
# 用途：從終端工作階段擷取文字
# 位置：終端模擬
# 輸入參數：
#   GetTextFrom [選項，預設 Field] 擷取文字的位置 — 要從中擷取文字的位置
#       可用值：TerminalEmulation.GetTextSource.Field（欄位）、TerminalEmulation.GetTextSource.EntireScreen（整個畫面）、TerminalEmulation.GetTextSource.CursorPosition（游標位置）、TerminalEmulation.GetTextSource.SpecificPosition（特定位置）

#       可用值：TerminalEmulation.GetFieldBy.FieldLabel（標籤）、TerminalEmulation.GetFieldBy.Index（索引）、TerminalEmulation.GetFieldBy.Position（位置）
#   TextLength [整數] 文字長度 — 要接收文字的長度
#   Index [整數] 索引 — 要尋找的欄位索引
#   FieldLabel [文字] 標籤 — 要尋找的欄位標籤
#   Row [整數] 列 — 畫面上欄位的垂直位置
#   Column [整數] 欄 — 畫面上欄位的水平位置
#   Session [TerminalSessionHandle] 終端工作階段 — 要處理的終端工作階段
# 產生的變數：
#   Text [文字] 終端文字 — 從終端工作階段擷取的文字
# 可能的錯誤：EmulatorCommunicationError、FieldIndexOutOfBoundsError、FieldLabelNotFoundError、ScreenPositionOutOfBoundsError、NoFieldFoundAtGivenPositionError、UnformattedTerminalScreenError、PositionCommandsNotSupportedByEmulatorError、OperationUnavailableForSessionTypeError
