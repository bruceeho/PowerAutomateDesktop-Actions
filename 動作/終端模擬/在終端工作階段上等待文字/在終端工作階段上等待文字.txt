# 動作：在終端工作階段上等待文字  (TerminalEmulation.WaitForTextOnTerminalSession)
# 英文名稱：Wait for text on terminal session
# 用途：等待特定文字顯示在終端工作階段中
# 位置：終端模擬
# 輸入參數：
#   Text [文字] 要等待的文字 — 等待在終端畫面或指定欄位上顯示的文字或規則運算式
#   IsRegEx [布林，預設 False] 規則運算式 — 指定是否要等待規則運算式而不等待純文字
#   WaitForTextOn [選項，預設 Screen] 等待文字的位置 — 等待文字顯示的位置
#       可用值：TerminalEmulation.WaitForTextSource.Screen（畫面）、TerminalEmulation.WaitForTextSource.Field（欄位）
#   GetFieldBy [選項，預設 FieldLabel] 欄位取得方式 — 指定尋找欄位的方式
#       可用值：TerminalEmulation.GetFieldBy.FieldLabel（標籤）、TerminalEmulation.GetFieldBy.Index（索引）、TerminalEmulation.GetFieldBy.Position（位置）
#   FieldLabel [文字] 標籤 — 要尋找的欄位標籤
#   Row [整數] 列 — 畫面上欄位的垂直位置
#   Index [整數] 索引 — 要尋找的欄位索引
#   Column [整數] 欄 — 畫面上欄位的水平位置
#   Timeout [整數，預設 0] 逾時 — 最長等待時間
#   Session [TerminalSessionHandle] 終端工作階段 — 先前開啟的終端工作階段
