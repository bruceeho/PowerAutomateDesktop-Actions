# ==================== 說明 ====================
# 動作：複製 Excel 工作表  (Excel.CopyExcelWorksheet)
# 英文名稱：Copy Excel worksheet
# 用途：從 Excel 文件複製工作表，並貼到相同或不同 Excel 執行個體的 Excel 文件上。
# 位置：Excel > 進階
# 輸入參數：
#   SourceInstance [ExcelInstanceHandle] Excel 執行個體 — 要處理的 Excel 執行個體。此變數先前必須已在「啟動 Excel」動作中指定
#   FindWorksheetMode [選項，預設 Name] 複製包含以下項目的工作表: — 指定要依名稱還是索引來尋找工作表
#       可用值：Excel.FindWorksheetBy.Index（索引）、Excel.FindWorksheetBy.Name（名字）
#   SourceWorksheetIndex [整數] 工作表索引 — 要複製的工作表的索引。編號從 1 開始，即第一個工作表的索引為 1，第二個為 2，以此類推。
#   SourceWorksheetName [文字] 工作表名稱 — 要複製的工作表的名稱
#   TargetInstance [ExcelInstanceHandle] 目標 Excel 執行個體 — 目標檔案的 Excel 執行個體。此變數先前必須已在「啟動 Excel」動作中指定。
#   TargetWorksheetName [文字] 工作表新名稱 — 工作表的新名稱
#   PasteWorksheetPosition [選項，預設 First] 將工作表貼為 — 指定要將複製的 Excel 工作表新增至現有工作表之前還是之後
#       可用值：Excel.WorksheetPosition.First（第一個工作表）、Excel.WorksheetPosition.Last（最後一個工作表）
# 可能的錯誤：CopyExcelWorksheetError、CopyExcelWorksheetSetNameError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
