# ==================== 說明 ====================
# 動作：自動填入 Excel 工作表中的儲存格  (Excel.AutoFillCells)
# 英文名稱：Auto fill cells in Excel worksheet
# 用途：根據其他範圍的資料，在 Excel 執行個體的使用中工作表中以資料自動填入範圍
# 位置：Excel > 進階
# 輸入參數：
#   Instance [ExcelInstanceHandle] Excel 執行個體 — 要處理的 Excel 執行個體。此變數先前必須已在「啟動 Excel」動作中指定
#   Mode [選項，預設 NamedCells] 範圍格式 — 指定如何使用具名單元格或絕對欄/列索引來參考範圍
#       可用值：Excel.AutoFillCellsMode.NamedCells（具名儲存格）、Excel.AutoFillCellsMode.CellCoordinates（具體範圍）
#   SourceCellName [文字] 來源儲存格名稱 — 代表自動填入來源範圍的名稱
#   DestinationCellName [文字] 目的地儲存格名稱 — 代表要自動填入之目的地範圍的名稱。來源範圍應該從同一個儲存格開始，並應包含在目的地範圍中
#   StartColumn [文字] 起始欄 — 兩個範圍第一欄的索引或字母
#   StartRow [整數] 起始列 — 兩個範圍最後一列的編號。編號從 1 開始
#   EndColumn [文字] 來源結尾欄 — 來源範圍最後一欄的索引或字母
#   EndRow [整數] 來源結尾列 — 來源範圍最後一列的編號。編號從 1 開始
#   DestinationColumn [文字] 目的地結尾欄 — 目的地範圍最後一欄的索引或字母
#   DestinationRow [整數] 目的地結尾列 — 目的地範圍最後一列的編號。編號從 1 開始
