# ==================== 說明 ====================
# 動作：刪除 Excel 工作表  (Excel.DeleteWorksheet)
# 英文名稱：Delete Excel worksheet
# 用途：刪除 Excel 執行個體的特定工作表
# 位置：Excel > 進階
# 輸入參數：
#   Instance [ExcelInstanceHandle] Excel 執行個體 — 要處理的 Excel 執行個體。此變數先前必須已在「啟動 Excel」動作中指定
