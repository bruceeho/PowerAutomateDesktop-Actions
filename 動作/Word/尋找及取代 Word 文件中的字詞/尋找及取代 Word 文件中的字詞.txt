# ==================== 說明 ====================
# 動作：尋找及取代 Word 文件中的字詞  (Word.FindAndReplaceWord)
# 英文名稱：Find and replace words in Word document
# 用途：在 Word 執行個體的使用中文件中尋找文字，並以其他文字取代。
# 位置：Word
# 輸入參數：
#   Instance [WordInstanceHandle] Word 執行個體 — 要處理的 Word 執行個體例。此變數先前必須已使用「啟動 Word」或「附加至執行中的 Word」動作完成指定。
#   AllMatches [布林，預設 False] 所有相符項目 — 是要在找到的所有相符項目中，還是僅在第一個相符項目中尋找及取代文字

#   TextToReplaceWith [文字] 要用以取代的文字 — 用於取代相符文字的文字
#   MatchWildCards [布林，預設 False] 使用萬用字元 — 是否對要尋找的文字使用萬用字元
#   MatchCase [布林，預設 False] 大小寫須相符 — 是否搜尋區分大小寫的資料
#   MatchEntireWord [布林，預設 False] 僅限全字拼寫皆相符 — 是否搜尋與指定文字相同的字詞
