# ==================== 說明 ====================
# 動作：從 Word 文件讀取  (Word.ReadFromWord)
# 英文名稱：Read from Word document
# 用途：從 Word 執行個體的文件讀取文字內容
# 位置：Word
# 輸入參數：
#   Instance [WordInstanceHandle] Word 執行個體  — 要處理的 Word 執行個體例。此變數先前必須已使用「啟動 Word」或「附加至執行中的 Word」動作完成指定。
#   ReadMode [選項，預設 WholeDocument] 擷取 — 要擷取整份文件、特定頁面還是書籤的內容
#       可用值：Word.ReadWordMode.WholeDocument（整份文件）、Word.ReadWordMode.Page（頁面）、Word.ReadWordMode.Bookmark（書籤）
#   Pages [文字，預設 1] 頁面 — 要讀取的 Word 文件的頁面。可提供頁面範圍或清單，如 2-5 (讀取第 2 頁至第 5 頁) 或 2,3,7 (讀取第 2、3、7 頁)。
#   Bookmark [文字] 書籤 — 要讀取的 Word 文件的書籤。
# 產生的變數：
#   WordData [文字] 將擷取的內容儲存至 — 擷取內容的值
# 可能的錯誤：ReadWordError、WordInstanceNotInitializedError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
