# 【模式 RunScriptAndFailOnTimeout】執行 PowerShell 指令碼，並在指定時間後失敗
Scripting.RunPowershellScript.RunScriptAndFailOnTimeout Timeout: 10 ScriptError=> ScriptError ScriptOutput=> ScriptOutput

# 【模式 RunScript】執行一些自訂 PowerShell 指令碼，並將其輸出擷取至變數
Scripting.RunPowershellScript.RunScript ScriptError=> ScriptError ScriptOutput=> ScriptOutput

# ==================== 說明 ====================
# 動作：執行 PowerShell 指令碼  (Scripting.RunPowershellScript)
# 英文名稱：Run PowerShell script
# 位置：指令碼處理
# 輸入參數：
#   FailOnTimeout [布林，預設 False] 逾時後失敗 — 指定 PowerShell 指令碼將無限期執行，還是在設定的一段時間過後失敗
#   Timeout [整數，預設 10] 逾時 — 等候指令碼完成的最大秒數 (-1 表示無限期)
#   Script [文字，選填] 要執行的 PowerShell 程式碼 — 要執行的 PowerShell 程式碼。指令碼中可包含變數，因為在執行 PowerShell 程式碼之前會先行評估這些變數
# 產生的變數：
#   ScriptError [文字] 錯誤 — 執行 PowerShell 程式碼期間可能發生的錯誤
#   ScriptOutput [文字] 輸出 — 指令碼的輸出
# 可能的錯誤：RunPowershellScriptError、ScriptTimeoutError
# 註：每種模式各有一行，只複製需要的那一行。未列出的參數由模式自動決定。
# 註：標示「選填」的參數預設不寫在代碼行裡，需要時自行加上（例如 ParamName: $'''值''')。
# 註：`` 代表需要自行填入的值（文字用 $'''內容''' 包起來，變數直接寫名稱）。
