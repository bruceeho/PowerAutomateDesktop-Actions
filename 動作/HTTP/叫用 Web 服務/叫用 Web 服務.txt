# ==================== 說明 ====================
# 動作：叫用 Web 服務  (Web.InvokeWebService)
# 英文名稱：Invoke web service
# 用途：透過傳送資料叫用 Web 服務並從 Web 服務擷取回應
# 位置：HTTP
# 輸入參數：
#   Url [文字] URL — Web 服務的 URL
#   Method [選項，預設 Get] 方法 — 用於叫用 Web 服務的 HTTP 方法
#       可用值：Web.Method.Get（GET）、Web.Method.Post（POST）、Web.Method.Connect（CONNECT）、Web.Method.Head（HEAD）、Web.Method.Put（PUT）、Web.Method.Delete（DELETE）、Web.Method.Options（OPTIONS）、Web.Method.Trace（TRACE）、Web.Method.Patch（PATCH）
#   Accept [文字，預設 application/xml] 接受 — Web 服務回應可接受的內容類型
#   ContentType [文字，預設 application/xml] 內容類型 — 將傳送至 Web 服務的要求的內容類型
#   CustomHeaders [文字，選填]
#   RequestBody [文字，選填]
#   SaveResponse [選項，預設 ToVariable] 儲存回應 — 指定傳回資料的儲存方式
#       可用值：Web.SaveResponse.ToVariable（將文字擷取到變數中 (適用於網頁)）、Web.SaveResponse.ToFile（儲存至磁碟 (適用於檔案)）
#   FileName [選項，預設 KeepOriginal] 檔案名稱 — 指定是否保留已下載檔案的原始檔案名稱，或指定新名稱
#       可用值：Web.FileName.KeepOriginal（保留原始檔案名稱 (僅指定目的地資料夾)）、Web.FileName.SpecifyFullPath（指定完整路徑 (目的地資料夾 + 自訂檔案名稱)）
#   DestinationFolder [FolderObject] 目的地資料夾 — 將儲存由 Web 服務所傳回檔案的資料夾
#   FilePath [FileObject] 目的地檔案路徑 — 將儲存由 Web 服務所傳回檔案的完整路徑 (資料夾加上檔案名稱)
#   ConnectionTimeout [整數，預設 30]
#   FollowRedirection [布林，預設 True]
#   ClearCookies [布林，預設 False]
#   FailOnErrorStatus [布林，預設 False]
#   EncodeRequestBody [布林，預設 True] 對要求本文編碼 — 指定是否應在叫用前對要求本文進行 URL 編碼
#   UserAgent [文字，預設 Mozilla/5.0 (Windows; U; Windows NT 5.1; en-US; rv:1.8.1.21) Gecko/20100312 Firefox/3.6]
#   UploadAttachments [布林，預設 False] 上傳附件 — 指定 Web 服務是否包括要上傳的檔案
#   Encoding [選項，預設 AutoDetect]
