PAD 出問題了：$ARGUMENTS

## 1. 先問清楚（缺的一次問）

1. 是**貼不進去**（貼上後沒反應），還是**貼得進去但執行出錯**？
2. 貼的是哪個檔案、整份還是只貼程式碼？貼到新流程還是已有內容的流程？
3. 執行出錯時：請使用者提供錯誤視窗的「位置」「錯誤訊息」（可截圖或複製詳細資料）。

## 2. 貼不進去：依序檢查

PAD 只要有一行解析不了就整段不貼，而且不顯示錯誤。

1. 換行是否全部 CRLF（LF 混用會失敗）。
2. 元素引用的單引號是否都是 `\'`。
3. `$'''...'''` 文字裡是否有 `'`、`<`、`>`、`||`，反斜線是否寫成 `\\`。
4. `CALL` 的子流程是否已在流程中建立。
5. 元素庫 JSON 是否能解析、元素名稱是否和程式碼引用一致；可試著把 `ScreenshotPath` 設成 `null`。
6. 動作名稱是否和 `正式流程\`、`demo\` 實際能跑的寫法一致（例如不能多 `Action` 字尾）。
7. 還找不到時，把程式碼拆成幾段讓使用者分批貼，二分法找出是哪一行。

## 3. 執行出錯：常見原因

- 「找不到具有選取器…」且訊息中還看得到 `%變數%`：選取器要改成自訂選取器。
- 找不到元素：頁面還沒載完、元素 Id 和錄製時不同（不同頁面、不同列），或分頁不是目標頁面。
- 變數未定義：輸入變數沒有傳入，或子流程執行順序不對。

## 4. 修正

- 另存新檔或修改 Claude 自己產生的檔案；使用者原有的檔案不要直接覆蓋。
- 修正後說明原因，並把新發現的規則提議補進 `README.md`。
