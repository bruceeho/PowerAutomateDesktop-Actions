---
description: 取得網頁欄位 Id 或建立 UI 元素（引導使用者開頁面，Claude 只讀不點）
argument-hint: <網站／頁面與要找的欄位，例如：訂單頁的回覆交期欄位>
---

需要網頁欄位資訊：$ARGUMENTS

## 1. 請使用者準備頁面

- 請使用者在 **Claude 的內建瀏覽器**（Browser 窗格）打開目標網站並**自己登入**。帳號密碼不要由 Claude 輸入，也不要在對話中重複。
- 請使用者用網站的選單進到目標頁面（有些網站直接改網址會被導回登入頁），並打開一筆有資料的單據，讓要找的欄位顯示出來。
- 使用者說好了之後，先用 tabs_context 確認目前分頁的網址是目標頁面。

## 2. 讀取（只讀不點）

- 用 JavaScript 讀表格標題與第 1 列每個欄位裡的 input／select／textarea 的 id、name、type，整理成「欄位標題 → Id」對照表。
- 表格欄位通常每列編號不同（例如 `ctl02`、`ctl03`），找出規律，告訴使用者哪一段要換成變數。
- **不要**點擊、填值或送出；不要觸發會跳出彈窗的動作。

## 3. 轉成 PAD 可用的元素

- 欄位每列不同時，用自訂選取器，例如 `input[Id="..._ctl%RowNo%_txtXXX"]`，元素庫 JSON 設 `"IsCustom": true` 和 `"CustomSelector"`。
- 元素名稱要和程式碼引用完全一致；引用時單引號寫成 `\'`。
- 如果使用者偏好在 PAD 錄製：提醒錄製後再把選取器改成文字編輯器模式並換上變數，元素名稱要和程式碼一致。

## 4. 回覆

- 列出欄位對照表，標明哪些是推測、哪些已從網頁確認。
- 提醒使用者讀完後可以登出或關閉分頁。
